### ROAD-22: Compliance Report Generator

**Priority:** Medium
**Category:** Tooling
**Status:** Planned
**Complexity:** Medium
**Dependencies:** ROAD-04

#### Description

For regulated industries, auto-generate compliance documentation from specs, QA reports, audit logs, and reviewer scores. Produces artefacts suitable for auditors.

#### Key Deliverables

- [ ] Compliance report skill or script that aggregates: spec overview, task completion, QA verdict, reviewer scores, security scan results, audit log entries
- [ ] Output format: PDF-ready markdown or structured JSON
- [ ] Mapping to common frameworks (SOC2 controls, ISO 27001, PCI-DSS) as optional templates

#### Notes

Start with a generic template. Framework-specific mapping is additive and company-dependent.

### ROAD-14: Multi-Spec Scrum Master

**Priority:** Medium
**Category:** UX
**Status:** Completed
**Complexity:** Large

#### Description

Extended `/scrum` agent that coordinates across multiple active specs with sprint board view, cross-spec dependency detection, and process health indicators.

#### Deliverables

- [x] Sprint Board view when invoked as `/scrum` with no args or `/scrum all`
- [x] Cross-spec dependency detection (overlapping repos, domains, potential merge conflicts)
- [x] Sprint health indicators (stale drafts, repeated rejections, repo contention)
- [x] Priority recommendations based on dependencies and blocking relationships

### ROAD-19: Onboarding Guide & Interactive Tour

**Priority:** High
**Category:** UX
**Status:** Planned
**Complexity:** Small
**Dependencies:** None

#### Description

A guided walkthrough for engineers new to the workspace. Reduces time-to-productivity when someone joins the company or starts using the framework for the first time.

#### Key Deliverables

- [ ] `docs/onboarding.md` with step-by-step guide: what the workspace is, how to set up, first spec, first pipeline run
- [ ] Curated example: a pre-written sample spec and sample target repo that new engineers can run `/dev` and `/qa` against to learn the flow
- [ ] Troubleshooting FAQ covering common first-time issues

#### Notes

Keep the example repo minimal (a tiny Node or Python app). The goal is hands-on learning, not reading docs.

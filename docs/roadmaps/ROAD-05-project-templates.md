### ROAD-05: Project Templates

**Priority:** Medium
**Category:** Tooling
**Status:** Planned
**Complexity:** Medium
**Dependencies:** None

#### Description

Scaffold new repos with BMAD+SDD conventions so teams start consistent. Templates for common stacks (Node API, Python service, Go CLI, React frontend).

#### Key Deliverables

- [ ] Template definitions under `.cursor/templates/` or `scripts/templates/`
- [ ] `/plan` awareness: detect greenfield projects and offer template selection

#### Notes
